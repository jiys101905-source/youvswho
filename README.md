# YOU vs WHO

언더독이 탑독에게 도전하는 **크로스핏 전용 1대1 챌린지 플랫폼** (대학 프로젝트).

- 매달: 1–2주차 온라인 예선 WHO'S NEXT (4인 포드 + 도전) → 3주차 16강(영상) → 4주차 8강(영상) → 다음 달 첫 주말 박스 오프라인 THE FINAL
- 레이팅(통산, 매칭 전용) + 예선 포인트(시리즈) 두 숫자만 사용
- AI 심판: 폰에서 MoveNet(17관절)으로 렙/NO REP 판독 → 상대 검토 → 관리자 확정
- 상금 = 수익 40% + 팬 부스트 + 스폰서 (우승 45 / 준우승 20 / 3위 9 / 4위 6 / 8강 탈락 각 3 / 16강 탈락 각 1 %)
- 실제 돈 베팅 없음 — 포인트 예측 리그만

## 구성
- `index.html`, `style.css`, `app.js` — 앱 (Firebase Auth + Firestore, Spark 무료 요금제)
- `aijudge.js` — 온디바이스 AI 심판 (TensorFlow.js, CDN 런타임 로드)
- `intro.js`, `assets/intro_*.mp4` — 스크롤로 진행되는 시네마틱 인트로 "THE FINAL"
- `firestore.rules` — 보안 규칙 (Firebase 콘솔 → Firestore → 규칙에 붙여넣기)

## 관리자 시작
1. 앱에서 가입 → 내 정보 → **관리자 등록 (최초 1회)**
2. 관리자 → **시즌 만들기** → (발표용) 가상 선수 만들기 → 포드 편성 → 기록 제출 → 주차 마감 처리

결제는 모두 데모이며 실제로 청구되지 않습니다.
